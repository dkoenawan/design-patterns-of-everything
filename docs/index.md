## Overview

A Solution Architect portfolio site built with Astro + React + MDX, deployed to GitHub Pages. The site presents eight architecture domains (Frontend, Backend, Infrastructure, DevOps, Network, Security, AI, Data) through an interactive horizontal-scroll starfield experience where each domain is rendered as a mouse-reactive constellation. The stack is zero-JS by default via Astro SSG, with React islands hydrated on the client for the interactive landing shell.
