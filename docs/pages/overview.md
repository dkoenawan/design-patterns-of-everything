# pages

## Purpose

Astro's file-based routing entry point for the portfolio site. Contains a single landing page that composes `BaseLayout` and `LandingShell` into a fully interactive horizontal-scroll experience — the sole public route of the site.

## Key files

- `src/pages/index.astro` — The only page file; imports `BaseLayout` for HTML structure and `LandingShell` as a `client:load` React island for the interactive constellation carousel.

## Public interface

**Routes generated:**

| Route | File | Notes |
|-------|------|-------|
| `/design-patterns-of-everything/` | `index.astro` | Root route; configured via `astro.config.mjs` base path |

No API routes, dynamic segments, or catch-all routes exist. Navigation between "pages" is implemented as scroll-snap panel switching in JavaScript, not Astro routing.

## Dependencies

**Internal:**
- `src/layouts/BaseLayout.astro` — HTML wrapper, meta tags, global CSS
- `src/components/LandingShell` — React interactive shell (`client:load`)

**External:**
- Astro 5.17.1 — static site generation and file-based routing
- `@astrojs/react` — enables React island hydration

**Transitive (via LandingShell):**
- `src/contexts/MouseContext`, `src/data/constellations`, `src/lib/starfield-engine`, all component files

## Gotchas

- **Single-page architecture**: All "navigation" is JavaScript scroll-snapping, not URL routing. Adding deep-linked domain pages requires new `.astro` files and coordinated link structure.
- **Full shell hydrated on load**: `client:load` hydrates the entire `LandingShell` immediately — no progressive enhancement. Without JavaScript the page is non-functional.
- **No fallback routes**: No 404 page, no dynamic routes, no catch-all segments. Deep-linking by URL is not supported.
- **Hardcoded SEO metadata**: Title and description are static props. Dynamic per-domain SEO requires either new pages or a metadata-injection strategy.
- **Tight coupling to `LandingShell`**: Any major UX paradigm shift (e.g., tabs, modals, multi-page) requires refactoring both this file and the entire component tree.
