# styles

## Purpose

The global CSS foundation for the portfolio site. Establishes base typography, layout constraints (`overflow: hidden` for horizontal scroll), component defaults (`.btn`, `.container`), and responsive rules. Acts as the stylesheet orchestrator — importing the brand identity system (theme variables and effects) and web fonts, then applying them to HTML semantic elements site-wide.

## Key files

- `src/styles/global.css` — The only file in this directory; imported once in `BaseLayout.astro`. Defines all base styles and imports brand CSS and `@fontsource` packages.
- `brand/brand-theme.css` *(external dependency)* — 250+ CSS custom properties covering color palette, typography scale, spacing, transitions, and shadows. Must be imported before `global.css` rules apply.
- `brand/brand-effects.css` *(external dependency)* — Advanced visual layer: glassmorphism, amber glow, focus rings, brand-tinted shadows.

## Public interface

**CSS Classes:**

| Class | Description |
|-------|-------------|
| `.btn` | Primary button with hover state and shadow elevation |
| `.container` | 1200px max-width centered layout container |
| `.display` | Display-level typography (5.16rem, light weight, tight tracking) |
| `.body-lg` | Large body text variant (1.23rem, relaxed line-height) |

**HTML element overrides:** `html`, `body`, `h1`–`h6`, `a`, `code`, `pre`, `section` — all styled via CSS variables from `brand-theme.css`.

**CSS variables consumed:** All typography (`--font-body`, `--text-h1`…), spacing (`--space-*`), color (`--color-bg`, `--color-text`…), shadow, radius, and transition variables from the brand system.

## Dependencies

**Internal:**
- `brand/brand-theme.css` — base variable system (imported first)
- `brand/brand-effects.css` — effects layer

**External (`@fontsource`):**
- `@fontsource/cormorant-garamond` — serif headings, weights 400 & 600
- `@fontsource/inter` — body text, weights 400, 500, 600
- `@fontsource/jetbrains-mono` — code/monospace, weights 400 & 500

**Framework:** Astro 5.17.1 via `BaseLayout.astro` (the sole importer).

## Gotchas

- **`overflow: hidden` on `html`/`body` is load-bearing**: Required for horizontal scroll-snap. Removing it breaks the entire landing page scroll experience.
- **Font weight imports must match usage**: Adding a new font weight in CSS requires a matching `@import` from `@fontsource`; otherwise the browser falls back silently.
- **No component-scoped styles here**: Component-specific CSS lives alongside components (e.g., `LandingShell.css`, `StarfieldCanvas.css`). This directory is global-only.
- **Dark-only design**: `prefers-color-scheme: light` media queries do not redefine colors. Light mode support requires restructuring `brand-theme.css` entirely.
- **`.container` conflicts with full-width panels**: The 1200px container class is defined but newer scroll-snap sections use full viewport width — mixing them requires care.
- **Legacy CSS starfield removed**: A comment notes that CSS starfield animations were removed and replaced by `Starfield.tsx`. Do not re-add CSS keyframe stars here.
- **Single mobile breakpoint at 640px**: No tablet breakpoint; screens 641–768px use desktop styles, which may cause layout issues.
