# components

## Purpose

This domain implements interactive, space-themed UI components for the horizontal-scrolling landing page. It visualizes software architecture domains as mouse-reactive constellations, coordinated through a central `LandingShell` orchestrator that manages the starfield backdrop, hero section, eight constellation panels, and footer.

## Key files

- `src/components/LandingShell.tsx` — Root orchestrator wrapping all panels in `MouseProvider`; coordinates Starfield backdrop, 10 panels (1 hero + 8 constellations + 1 footer), and navigation indicator.
- `src/components/ConstellationPanel.tsx` — SVG constellation for each architecture domain; renders magnitude-scaled stars, connecting edges, and proximity-based glow driven by mouse position.
- `src/components/Starfield.tsx` — Canvas wrapper for `StarfieldEngine`; handles resize and forwards mouse position updates from context.
- `src/components/HeroPanel.tsx` — Static title section with animated heading and "Begin exploration" CTA that smooth-scrolls to the first domain panel.
- `src/components/PanelIndicator.tsx` — Fixed bottom navigation dots tracking active panel via scroll position; click-to-jump to any panel.
- `src/components/FooterPanel.tsx` — Stateless footer panel at the end of the scroll carousel.
- `src/components/LandingShell.css` — Scroll-snap and layout CSS for the horizontal panel container.

## Public interface

All components are default exports (also available as named exports):

| Export | Props |
|--------|-------|
| `LandingShell` | none |
| `ConstellationPanel` | `panelIndex: number` + `ConstellationDomain` data |
| `HeroPanel` | `onExplore: () => void` |
| `Starfield` | none |
| `PanelIndicator` | `count: number`, `labels: string[]`, `trackRef: React.Ref` |
| `FooterPanel` | none |

Context: `MouseProvider` (from `src/contexts`) wraps all interactive children; they access position via `useMousePosition()`.

## Dependencies

**Internal:**
- `src/contexts/MouseContext.tsx` — global mouse position context
- `src/data/constellations.ts` — 8 domain definitions (`CONSTELLATIONS` export)
- `src/lib/starfield-engine.ts` — canvas rendering engine

**External:**
- React 19.2.4 (`useEffect`, `useRef`, `useState`, `useMemo`, `useContext`)
- Astro 5.17.1 (loads components with `client:load` directive)
- CSS variables from global theme (`--color-domain-*`, `--domain-color`, fonts, spacing)

## Gotchas

- **Silent failure without `MouseProvider`**: ConstellationPanel and Starfield will not glow or respond to mouse without the context wrapper — no error is thrown.
- **Stale star rects on resize**: `ConstellationPanel` recalculates proximity via `getBoundingClientRect()` only on mouse move, not on resize; positions stay stale until next mouse event.
- **Snap vs smooth-scroll conflict**: `scroll-snap-type: x mandatory` can override `scrollTo({ behavior: 'smooth' })` from `PanelIndicator`, causing snap-jump behaviour on some browsers.
- **Hardcoded panel count**: `TOTAL_PANELS` = `CONSTELLATIONS.length + 2` is derived at import time; adding/removing domains also requires updating the JSX tree in `LandingShell.tsx` manually.
- **Canvas 2D context fallback is silent**: `Starfield` logs a warning if the canvas context is unavailable but renders nothing; no CSS fallback stars are defined.
- **z-index layer assumptions**: Starfield is `z-index: -1`, `PanelIndicator` is `z-index: 100`; inserting new fixed elements between these layers requires careful z-index coordination.
