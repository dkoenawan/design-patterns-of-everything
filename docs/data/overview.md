# data

## Purpose

Holds the canonical constellation data structure powering the portfolio's central visual metaphor. Defines eight architectural domains (Frontend, Backend, Infrastructure, DevOps, Network, Security, AI, Data) as constellation maps — each with star nodes representing pattern concepts and edges representing their relationships — enabling the landing page's interactive stellar visualization.

## Key files

- `src/data/constellations.ts` — The single authoritative file; defines `StarNode` and `ConstellationDomain` TypeScript interfaces, and exports the `CONSTELLATIONS` array containing all 8 domains with 48 total star nodes and their edges.

## Public interface

| Export | Type | Description |
|--------|------|-------------|
| `StarNode` | interface | `{ id, label, x, y, magnitude: 1\|2\|3, href? }` — individual concept node |
| `ConstellationDomain` | interface | `{ domain, name, shortName, cssClass, stars, edges }` — complete domain definition |
| `CONSTELLATIONS` | `ConstellationDomain[]` | Array of 8 domain objects; primary data consumed by components |

## Dependencies

**Internal:** None — pure TypeScript with no imports from other `src/` directories.

**Consumers:**
- `src/components/ConstellationPanel.tsx` — renders star nodes and edges as SVG
- `src/components/LandingShell.tsx` — iterates domains to create panels

**External:** None.

## Gotchas

- **All coordinates are hardcoded**: Star positions (`x`, `y` as percentages) and edges are literal values; any domain change requires direct file edits and a site rebuild.
- **Magnitude is a union type** (`1 | 2 | 3`): Adding a fourth magnitude tier requires an interface change.
- **`cssClass` must match stylesheet**: Each domain's `cssClass` (e.g., `domain-frontend`) must have a corresponding CSS definition or stars render unstyled.
- **`href` on `StarNode` is unused**: Present as scaffolding for future clickable pattern navigation; no component currently reads it.
- **No edge validation**: Edge `from`/`to` IDs are not checked against existing star IDs at runtime; typos silently produce missing edges in `ConstellationPanel`.
- **Static asset**: Patterns cannot be modified dynamically; the site must be rebuilt and redeployed to reflect any constellation change.
